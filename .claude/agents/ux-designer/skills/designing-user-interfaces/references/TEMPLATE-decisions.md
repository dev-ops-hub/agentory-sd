## UXD-1: <Title>

**Status:** Proposed  **Cost to reverse:** low | medium | high  **Trace:** <FR-x / NFR-x / constitution principle / doctrine rule / ASSUMPTION A<k>>

**Context.** The user need or constraint, in two to four lines.

**Options.**

| Option | For | Against |
|---|---|---|
| A (chosen) | | |
| B | | |

**Decision.** One sentence.

**Rationale.** Why A over B, tied to the user's task and to the trace above.

**Consequences.** What this fixes for later screens, what it gives up, what to revisit and when.
